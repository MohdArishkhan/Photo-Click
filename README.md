# Photo-Click

Photo-Click is a web application for capturing, viewing, and managing photos. This project contains a frontend built with HTML, CSS, and JavaScript.

## Features
- Capture photos using your device camera
- View and manage your photo collection
- Simple and intuitive user interface

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/MohdArishkhan/Photo-Click.git
   ```
2. Open the `Frontend` folder and launch `page.html` in your browser.

## Folder Structure
```
Frontend/
  page.html
  page.css
  page.js
```
